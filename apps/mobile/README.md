# Ad Platform Mobile

Flutter-приложение для управления рекламой через сервисы Ad Platform. Поддерживаются Android и iOS.

## Возможности

- регистрация, вход и восстановление JWT-сессии;
- защищённое хранение токена в Keychain/Android Keystore;
- главный экран с балансом и сводкой;
- создание, редактирование и удаление кампаний;
- площадки, рекламные места, публичные коды и каталог форматов;
- объявления и креативы внутри кампании, включая привязку к рекламному месту, целевую ссылку и вес выдачи;
- выбор изображения или видео из галереи, загрузка медиа-креатива и превью изображений;
- отправка креативов на модерацию, отображение статуса и причины отклонения;
- очередь модерации с одобрением и отклонением для пользователей с ролью `admin`;
- таргетинг объявления по возрасту, полу, интересам, странам, регионам, городам, типам устройств и операционным системам;
- общий бюджет и дневной лимит кампании с отображением текущего расхода;
- расписание кампании по датам, дням недели и часам UTC;
- CPM-ставка объявления и фактическая стоимость показов;
- пополнение, вывод и история финансовых операций;
- аналитика показов, кликов, CTR и расходов;
- фильтрация аналитики по кампании;
- обновление данных жестом pull-to-refresh.

Пустые поля таргетинга означают выдачу всей аудитории. Страны вводятся ISO-кодами из двух букв, а несколько интересов, регионов и городов разделяются запятыми. Для интересов объявление подходит при совпадении хотя бы одного значения.

Для креативов приложение принимает JPEG, PNG, GIF и WebP до 10 МБ, а также MP4, WebM и MOV до 100 МБ. Ограничения повторно проверяются сервером по фактическому содержимому файла.

После создания креатив остаётся черновиком. Отправьте его на проверку через меню карточки. Администратору после входа доступен отдельный раздел «Модерация» с очередью, историей решений и обязательным комментарием при отклонении.

## Локальный запуск

Сначала из корня репозитория запустите бэкенд:

```bash
make up-detached
```

Затем запустите приложение:

```bash
cd apps/mobile
flutter pub get
flutter run
```

Для Android Emulator автоматически используется `10.0.2.2`, для iOS Simulator — `127.0.0.1`.

## Физическое устройство

Укажите LAN-адрес компьютера с запущенным бэкендом:

```bash
flutter run \
  --dart-define=AUTH_API_URL=http://192.168.1.10:8000 \
  --dart-define=ADS_API_URL=http://192.168.1.10:8080 \
  --dart-define=ANALYTICS_API_URL=http://192.168.1.10:8100
```

Телефон и компьютер должны находиться в одной сети. Для production передавайте HTTPS-адреса тем же способом.

## Сборка

```bash
flutter analyze
flutter build apk --release
flutter build ios --release
```

Release-сборка Android требует собственного signing config, а публикация iOS — Apple Developer Team и provisioning profile.

## Структура

- `lib/src/core` — конфигурация API, тема и HTTP-клиент;
- `lib/src/data` — репозиторий трёх backend API;
- `lib/src/domain` — модели предметной области;
- `lib/src/state` — сессия и состояние рабочего пространства;
- `lib/src/ui` — экраны авторизации, кампаний, площадок, финансов, аналитики и профиля.
